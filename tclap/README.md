# TCLAP (Templatized C++ Command Line Parser)

Unmodified headers of TCLAP 1.2.5, used by the command-line parsing code that
`dcmqiGenerateCLP` generates for the dcmqi applications.

- Project: https://tclap.sourceforge.net/
- Source: `tclap-1.2.5.tar.gz` from https://sourceforge.net/projects/tclap/files/
  (SHA-256 `bb649f76dae35e8d0dcba4b52acfd4e062d787e6a81b43f7a4b01275153165a6`),
  directory `include/tclap/`
- License: MIT, see [COPYING](COPYING)

To build against a system copy instead (e.g. Debian's `libtclap-dev`), set
`TCLAP_INCLUDE_DIR` to the directory containing `tclap/CmdLine.h`.
